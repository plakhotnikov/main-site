# Voucher - Лабораторная работа 3 (вариант 1-3)

## Описание
Система оформления туристических путевок. Вариант 1 (Туристическая путевка), шаблон 3.
Готовый table-based HTML-шаблон (583x614px, фиксированная высота). Шаблон менять нельзя.

## Структура проекта
```
Voucher/
├── index.php              — Главная: авторизация (cookies), admin/123, кнопка Выйти
├── css/style.css          — Стили (Tahoma 10px, Safari text-size-adjust fix)
├── images/                — Декоративные GIF-картинки шаблона (не трогать)
├── generated/             — Сгенерированные DOCX файлы
├── pages/
│   ├── data.php           — Массивы данных (типы путевок, цены, страны, услуги, питание)
│   ├── order.php          — Шаг 1: тип путевки (select), контакты, вид питания (radio)
│   ├── bill.php           — Шаг 2: страна (radio), доп.услуги (checkbox), кол-во дней
│   ├── basket.php         — Шаг 3: итоговая информация, расчет суммы, кнопки почта/файл
│   ├── save_file.php      — Генерация DOCX через PHPWord, скачивание
│   ├── send_email.php     — Отправка email через mail() с HTML, inline-картинкой и вложением DOCX
│   ├── download.php       — Скачивание файлов из generated/
│   ├── index-3.php        — О компании (статика)
│   ├── index-4.php        — Контакты (статика)
│   └── index-5.php        — Инфо (статика)
├── examples/              — Скриншоты-образцы из задания
│   ├── template1.png      — Пустой шаблон DOCX
│   ├── template2.png      — Заполненный шаблон DOCX
│   ├── auth.jpg, order_page.jpg, bill_page.jpg, basket_page.jpg, voucher.png
└── pic/                   — Фото для типов путевок (cruise.jpg, safari.jpeg, gastro_tur.jpg)
```

## Архитектура
- **Авторизация**: cookies (`auth_user`), логин `admin`, пароль `123`
- **Данные между страницами**: `$_SESSION` (order → bill → basket)
- **Все данные**: массивы в `data.php` (без БД)
- **Генерация DOCX**: PHPWord (`vendor/phpoffice/phpword`), autoload: `../../../vendor/autoload.php` (3 уровня вверх от pages/)
- **Кодировка**: UTF-8 (исходно было iso-8859-1)

## Формула стоимости
```
Итого = Базовая цена + Наценка страны + (Цена питания * Кол-во дней) + Сумма доп. услуг
```

## DOCX шаблон (save_file.php)
- Оператор: **Плахотников В. А.**
- Шапка: одна таблица 3:1 (7500/2500 twip)
  - Строка 1: пусто | "Утверждено Главным..." (выровнено влево)
  - Строка 2: пусто | "Код формы по ОКУН"
  - Строка 3: "Туроператор Какой-то" | "061000" (на одном уровне)
  - Строка 4: "г. Ухта, ИНН 123456987" | пусто
- Подчеркивание строк через `borderBottomSize` на параграфе (линия на всю ширину ячейки)
- "Тип путевки:" — жирный label через TextRun
- Доп. услуги — нумерованный список (1. 2. 3.)
- Телефон и email — без жирного шрифта

## Email (send_email.php)
- Тема: "Для заказа «Туристическая путевка»"
- Верстка по образцу voucher.png:
  - "Уважаемый {Имя}!" — сверху по центру, жирным
  - Таблица: картинка тура слева (280px, inline CID), текст справа (путевка, страна, питание, услуги)
  - "Полная стоимость тура: {сумма} руб." — внизу
  - "Почти настоящая компания." — курсивом
- Вложение: DOCX файл (если не был создан ранее — генерируется автоматически)
- Картинка встраивается как multipart/related с Content-ID
- Путь к картинкам из pages/: `__DIR__ . '/' . $image_rel_path` (пути в data.php относительны к pages/)

## Docker
- **docker-compose.yml**: 3 сервиса — web (PHP/Apache), db (MySQL), mailpit
- **Mailpit**: UI на порту `8025`, SMTP на `1025`
- **msmtp**: настроен в Dockerfile как sendmail_path, шлет через mailpit:1025
- **docker-entrypoint.sh**: создает `generated/` для Voucher и Plakhotnikov_office_6

## Известные особенности
- Safari увеличивает мелкий шрифт в таблицах → инлайн `style="font-size:10px"` на `<td>` и `<input>` в order.php
- Картинки на basket.php ограничены `width="220"` HTML-атрибутом (CSS max-width не работает в table layout)
- Фиксированная высота контентной области оставлена как в оригинале
- `vendor/` находится в корне проекта (`main-site/vendor/`), путь из pages/: `/../../../vendor/autoload.php`
- Радиокнопки и чекбоксы обернуты в `<div>` для отображения каждого в своей строке
